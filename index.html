Workshop Overview

This workshop is designed to introduce participants to the fundamentals of Git and GitHub, essential tools for version control and collaborative software development. Attendees will learn how to manage code repositories, track changes, and collaborate effectively with others.

Workshop Schedule

  • 10:00 AM - 10:30 AM: Introduction to Version Control
  • 10:30 AM - 11:30 AM: Getting Started with Git
  • 11:30 AM - 12:30 PM: Hands-on Git Exercises
  • 12:30 PM - 1:30 PM: Lunch Break
  • 1:30 PM - 2:30 PM: Introduction to GitHub
  • 2:30 PM - 3:30 PM: Collaborative Workflows on GitHub
  • 3:30 PM - 4:00 PM: Q&A and Wrap-up
